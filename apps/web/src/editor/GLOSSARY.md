# AiccCut UI 용어집 (한국어)

모든 화면 문구는 한국어 존댓말로 쓴다. 대상은 영상 편집을 처음 배우는 직장인이다.
같은 개념은 반드시 아래 표의 낱말을 쓴다. 영어를 남기는 경우는 표에 "영어 유지"로 표시한 것만이다.

## 원칙

- 짧게. 버튼은 2~4글자(예: 삭제, 복제, 내보내기). 툴팁·안내문은 한 문장.
- 존댓말 어미는 안내문에만("클립을 선택하세요"). 라벨·버튼은 명사형("불투명도", "내보내기").
- 단축키 표기(⌘ ⇧ ⌥ S Space Esc), 파일명, 폰트 이름, 코덱(MP4 · H.264), 해상도(1920×1080), fps, px, em, 비율(16:9)은 영어 유지.
- 숫자 뒤 단위는 붙여 쓴다: 30fps, 1080p, 12.4초(코드에서 `s`로 표기하던 초는 "초"로).
- 타임코드 형식 00:00:12.04는 그대로.
