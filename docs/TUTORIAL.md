# AiccCut 15분 튜토리얼

영상 편집을 처음 해 보는 분을 기준으로 씁니다. 순서대로 따라 하면 15분 안에 자막과 애니메이션이 들어간 짧은 영상 한 편을 만들고 프로젝트 파일로 내보내게 됩니다.

준비물: 내 컴퓨터에 있는 영상 파일 1개(휴대폰으로 찍은 mp4면 충분합니다), 사진 1장, 배경음악 1곡(없어도 됩니다).

## 0. 실행하기

터미널을 열고 아래를 한 줄씩 입력합니다. (터미널은 맥에서 `⌘ + Space` 누르고 "터미널"을 치면 나옵니다.)

```sh
cd apps/web
bun install
bun run dev
```

브라우저에서 `http://localhost:5173` 을 엽니다. 처음 열면 샘플 프로젝트 6개가 보입니다.

![홈](screens/01-home.png)

> 화면 위 해 아이콘을 누르면 밝은 테마로 바뀝니다. 취향대로 고르세요.

## 1. 먼저 샘플을 눌러 보기 (2분)

첫 번째 타일 "Claude Code 강의 6화"를 클릭합니다. 이미 클립 12개가 들어 있어서 편집기가 어떻게 생겼는지 바로 볼 수 있습니다.

![편집기](screens/03-editor.png)

화면은 네 부분입니다.

| 위치 | 이름 | 하는 일 |
| --- | --- | --- |
| 왼쪽 세로 막대 | 레일 | 미디어·텍스트·효과·오디오 패널을 여닫습니다. 숫자 키 1~4로도 됩니다. |
| 가운데 위 | 미리보기 | 지금 재생 헤드가 있는 순간의 화면입니다. |
| 가운데 아래 | 타임라인 | 시간 순서로 클립이 놓입니다. 빨간 세로선이 재생 헤드입니다. |
| 오른쪽 | 속성 | 고른 클립의 위치·크기·효과·글자 설정입니다. |

해 볼 것 세 가지:

1. `Space`를 눌러 재생하고, 다시 눌러 멈춥니다.
2. 타임라인 위 눈금자(0:00, 0:05…)를 아무 데나 클릭합니다. 재생 헤드가 그리로 갑니다.
3. 타임라인의 보라색 클립 `screen_hooks_demo`를 클릭합니다. 오른쪽 속성 패널이 채워지고, 클립 아래에 얇은 줄 6개(키프레임 레인)가 펼쳐집니다.

다 봤으면 왼쪽 위 `←`로 홈에 돌아갑니다.

## 2. 새 프로젝트 만들기 (1분)

첫 타일 "새 프로젝트"를 클릭합니다.

![새 프로젝트](screens/02-new-project.png)

- 이름: "첫 영상"
- 화면 비율: 유튜브면 16:9, 릴스·쇼츠면 9:16
- 프레임 레이트와 해상도는 그대로 두어도 됩니다.

`프로젝트 만들기`를 누르면 빈 편집기가 열립니다.

## 3. 파일 가져오기 (2분)

왼쪽 미디어 패널이 비어 있고 점선 상자가 보입니다.

![빈 프로젝트](screens/14-empty-project.png)

영상 파일을 브라우저 창 안으로 끌어다 놓습니다. 어디에 놓아도 됩니다. 사진과 음악도 같은 방법으로 넣습니다.

> 다른 방법: `⌘I`를 누르거나 패널 위 `가져오기`를 클릭하면 파일 선택창이 뜹니다. 복사한 파일을 `⌘V`로 붙여넣어도 됩니다.

잠깐 진행 바가 지나가고 타일에 실제 썸네일이 뜹니다.

## 4. 타임라인에 올리기 (2분)

미디어 타일을 타임라인의 `비디오 1` 줄로 끌어다 놓습니다. 놓기 전에 점선 상자가 어디에 들어갈지 미리 보여줍니다.

더 빠른 방법: 재생 헤드를 원하는 시간에 두고 타일을 **더블클릭**하면 그 자리에 들어갑니다. 영상은 비디오 트랙으로, 음악은 음악 트랙으로 알아서 갑니다.

사진도 같은 방법으로 `비디오 2` 줄에 올려 보세요. 위 줄이 아래 줄 위에 겹쳐 보입니다.

## 5. 자르고 다듬기 (3분)

영상에서 필요 없는 앞부분을 잘라 봅니다.

1. 재생 헤드를 자를 지점으로 옮깁니다. `←` `→`는 1프레임씩, `⇧←` `⇧→`는 10프레임씩 움직입니다.
2. 클립을 클릭해 선택하고 `S`를 누릅니다. 클립이 둘로 나뉩니다.
3. 앞쪽 조각을 클릭하고 `Backspace`로 지웁니다.

빈 자리가 남았죠? `⇧Backspace`로 지우면 뒤 클립이 앞으로 당겨집니다. 이걸 **리플 삭제**라고 합니다.

클립 양 끝을 잡고 끌면 길이가 줄어듭니다(트림). 끌 때 몇 초 줄었는지 칩이 따라다닙니다. 클립 가운데를 잡고 끌면 위치가 옮겨지고, 다른 클립 끝에 자석처럼 붙습니다.

![우클릭 메뉴](screens/05-clip-menu.png)

클립을 **우클릭**하면 이 모든 명령이 메뉴로 나옵니다. 단축키를 외우기 전엔 이 메뉴가 편합니다. 화면 맨 아래 힌트 바도 지금 누를 수 있는 키를 알려줍니다.

실수했으면 `⌘Z`. 100단계까지 되돌아갑니다.

## 6. 자막 넣기 (2분)

왼쪽 레일에서 `텍스트`를 누르거나 `2`를 누릅니다.

![텍스트](screens/06-text-panel.png)

프리셋 중 `자막`을 클릭하면 재생 헤드 위치에 자막 클립이 생기고 바로 선택됩니다. 아래 `내용` 칸에 글을 치면 미리보기에 실시간으로 바뀝니다.

미리보기 화면에서 글자를 직접 끌어 옮길 수 있고, 모서리를 잡으면 크기가 바뀝니다.

글꼴을 바꾸려면 `찾아보기`를 누릅니다.

![글꼴 찾아보기](screens/07-font-browser.png)

위 칸에 내 문장을 치면 모든 글꼴이 그 문장으로 다시 그려져서 한눈에 비교됩니다. 마음에 드는 걸 클릭하면 바로 적용되고, 별을 누르면 즐겨찾기에 모입니다. 글꼴 120여 종은 구글 폰트에서 필요할 때 내려받으니 인터넷이 연결돼 있어야 합니다.

## 7. 움직임 주기 (2분)

자막이 스르륵 나타나게 해 봅니다.

1. 자막 클립을 선택하고 재생 헤드를 클립 시작으로 옮깁니다.
2. 오른쪽 속성 패널 `합성` 카드에서 `불투명도` 옆 시계 모양(스톱워치)을 누릅니다. 이제 이 값은 시간에 따라 바뀔 수 있습니다.
3. 불투명도를 0으로 내립니다. 타임라인 아래 레인에 다이아몬드가 찍힙니다.
4. 재생 헤드를 1초 뒤로 옮기고 불투명도를 100으로 올립니다. 다이아몬드가 하나 더 찍힙니다.

![속성·키프레임](screens/04-inspector-keyframes.png)

재생해 보면 자막이 1초 동안 서서히 나타납니다. 다이아몬드를 좌우로 끌면 타이밍이 바뀝니다. 위치·크기·회전도 같은 방식으로 움직일 수 있습니다.

## 8. 효과 붙이기 (1분)

영상 클립을 선택하고 `3`을 누릅니다(효과 레일).

![효과](screens/08-effects-panel.png)

`블러`를 클릭하면 영상이 흐려집니다. 속성 패널 `효과` 카드에서 강도를 조절하거나, 스위치로 껐다 켜거나, 순서를 바꿉니다. 밝기·대비·채도·비네트·선명도도 같습니다.

## 9. 내보내기 (1분)

오른쪽 위 `내보내기`를 누르거나 `⌘E`.

![내보내기](screens/09-export.png)

형식과 해상도를 고르고 `다음`, 저장 위치를 고르고 `렌더링 시작`. 진행 바가 끝까지 가면 `프로젝트 파일 다운로드`가 나옵니다.

> 솔직하게 알려드립니다. 이 버전에는 영상 인코더가 아직 없습니다. 내보내기는 렌더링 과정을 실제로 밟지만, 결과물은 mp4가 아니라 프로젝트 파일(.aicccut.json)입니다. 화면에도 같은 안내가 적혀 있습니다.

## 10. 더 빨라지기

- `⌘K`: 명령 팔레트. "분할", "북마크"처럼 이름을 치면 바로 실행됩니다.
- `?`: 단축키 화면. 키보드 그림에서 키를 누르면 그 명령이 실행되니, 눌러 보며 익히세요.

![단축키](screens/13-shortcuts.png)

자주 쓰는 키만 추리면 이렇습니다.

| 키 | 하는 일 |
| --- | --- |
| `Space` | 재생 / 일시정지 |
| `←` `→` | 1프레임 이동 |
| `J` `K` `L` | 뒤로 재생 / 정지 / 앞으로 재생. 두 번 누르면 배속 |
| `S` | 재생 헤드에서 분할 |
| `Backspace` / `⇧Backspace` | 삭제 / 리플 삭제 |
| `[` `]` | 시작점·끝점을 재생 헤드로 |
| `⌘D` | 복제 |
| `⌘Z` / `⇧⌘Z` | 실행 취소 / 다시 실행 |
| `B` | 북마크 |
| `N` | 스냅 켜기/끄기 |
| `=` `-` `⇧Z` | 타임라인 확대 / 축소 / 전체 맞춤 |
| `1`~`4` | 미디어·텍스트·효과·오디오 패널 |
| `I` | 속성 패널 접기/펴기 |

## 알아두면 좋은 것

- **저장은 자동**입니다. 위쪽 가운데 "저장됨"이 보이면 끝. 이 브라우저에만 저장되니 다른 컴퓨터에서는 보이지 않습니다.
- **가져온 파일은 브라우저를 새로고침하면 색상 타일로 바뀝니다.** 파일 자체는 저장되지 않고 위치·길이 정보만 남습니다. 다시 가져오면 됩니다.
- **음악·음성 트랙은 아직 소리가 나지 않습니다.** 영상에 붙은 소리만 납니다.
- 트랙 이름 옆 `M` `S` `L` 눈 아이콘은 음소거·솔로·잠금·숨기기입니다. 잠그면 그 줄은 실수로 건드릴 수 없습니다.
